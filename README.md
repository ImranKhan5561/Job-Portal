# Job Portal

The Job Portal System is a web-based platform that connects job seekers with employers, 
simplifying the recruitment process. This system provides an efficient way for candidates to 
search and apply for jobs while enabling employers to post job openings and manage 
applications. The portal includes features such as user registration, job postings, resume 
uploads, job search filters, application tracking, Live Chatting etc. It enhances accessibility by offering 
personalized job recommendations based on skills, experience, and preferences.
